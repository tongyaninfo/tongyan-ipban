Tongyan IPBan User Guide

The local console shows login events, current connections and sessions, and manages ban records, IP lists, policies, logs and backups.

Runtime overview

Trend ranges are 24 hours, last 7 days and last month. Times use the browser's local time zone.

Live state

Current Sessions lists SSH, RDP, WinRM and VNC activity with usernames where login records match, and supports disconnection. Current Network Connections shows TCP endpoints, processes and connection states, with ban and disconnect actions. Both pages support manual refresh and live updates. An established connection does not imply successful authentication; missing information shows collection status.

Security events

Login events show success or failure, username, remote address, port, process and evidence source. Ban decisions and ban records show execution results and lifecycle history.

Access control

IP lists support IP/CIDR, priority, effective time and expiration. Policies support thresholds, windows, observation, cooldown and ban duration.

System management

System logs can be searched and exported. Uploaded certificates take effect after the service is restarted.
