# 文档资源

本目录存放 README 与文档中使用的截图、示意图等静态资源。产品截图由真实管理台页面使用合成数据渲染，参见[项目 README](../../README.md)。

## 脱敏要求

- 使用合成数据：站点与内网服务名称、来源 IP、账号、邮箱、封禁原因、策略阈值与操作者全部为示例，不使用真实业务信息、真实名单或真实封禁记录。
- 来源地址使用文档保留网段（如 IPv4 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`，IPv6 `2001:db8::/32`）；Cookie、Token、`Authorization` 等敏感头不出现。
- 不展示真实攻击流量、真实用户访问记录、真实 GeoIP 数据片段或可定位到个人/组织的网络信息；地域截图使用示例国家或地区。
- 不展示宿主防火墙、容器宿主或部署环境的真实主机名、地址、路径与命令输出；涉及部署的截图只能使用占位环境。
- 截图中的角标、浏览器书签、系统通知栏、终端历史等无关内容裁掉或打码。

## 命名与引用

- 命名：`<主题>-<视口/场景>.png`，例如 `ban-list-desktop.png`；同名多语言用 `-zh-CN` / `-en-US` 区分。
- 引用使用相对路径，中文替代文本说明页面内容并注明合成演示数据；示例文件名仅供说明，实际引用以本目录真实文件为准。
- 图片只用于说明界面与交互，不作为功能、性能或封禁效果已验收的证明；文档中注明「合成演示数据」。

## 其他

- 大图先压缩，避免把原始高分辨率截图直接提交；动态演示优先使用短 GIF 或链接，不提交大视频。
- 设计稿源文件、导出中间件与未脱敏原图不进入仓库。
- 删除或替换截图时同步更新引用，避免死链。
