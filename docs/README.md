# 通研 IPBan 文档中心

本目录维护通研 IPBan 的方案、架构决定、接口合同与版本记录。根 [README](../README.md) 是产品入口，本页是导航；两者都只描述当前真实状态。

## 当前阶段

| 部分 | 状态 |
| --- | --- |
| 目录结构、开发约定、方案文档 | 已建立（2026-11-07） |
| 后端工程、Agent 和管理 API | 四个 .NET 项目已建立；Linux 当前连接、IPC 和人工封禁已接入 |
| 封禁判定引擎 | Engine 类库和基础测试已建立，名单/策略业务仍待完成 |
| 管理台前端 | 已移除模板示例页面，保留 IPBan 业务路由；运行总览、当前连接/会话、系统管理和日志页面已接入 |
| 数据库、传感器和防火墙 provider | SQLite v2 自动初始化、Linux SSH/`ss` 基础传感器、Provider 探测和状态 IPC 已建立 |
| 部署、发布和验收 | macOS arm64 AOT 冒烟、隔离 Linux 环境完成自包含启动与 SSH 连接处置验证 |
| MCP 服务 | 可选扩展，默认停止；需管理员显式启用并创建受限 API Key，调用进入审计 |

当前源码基线为 0.1.0，处于工程初始化阶段。目录存在、文档写完都不能推导为能力已实现或已上线。

## 维护规则

- 使用中文、UTF-8、相对路径，不写真实凭据、主机信息、密钥或个人绝对路径。
- 方案、接口、决定、变更和版本分别维护；同一事实只维护一处，其余使用链接。
- 区分规划、已实现、已验证和已部署；文档完成不等于功能完成。
- 删除、改名或移动文档时同步更新引用。
- 截图和示意图使用合成数据，来源 IP、账号、原因和操作者脱敏。
