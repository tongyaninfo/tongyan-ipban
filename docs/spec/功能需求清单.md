# 通研 IPBan 功能需求清单

> 版本 v0.2（2026-11-07）。需求与[一期实施方案](一期实施方案.md)一致。本文描述需求与验收点；工程与基础实现已建立，具体进度和验证边界以文档中心「当前阶段」和实施方案为准，不代表对应能力已全部实现或已验证。

## 一、共同合同

- 管理 API 使用 ApiResult<T> 和真实 HTTP 状态码。
- 判定引擎保持纯函数：不读库、不写文件、不执行命令、不发起网络请求。
- 所有时间存储 UTC，对外使用带时区的 ISO 8601；界面按 Asia/Shanghai 展示。
- ID 使用 IIdService/YiteIdService；双进程不得共用同一 WorkerId；JSON 中 long 型 ID 使用十进制字符串。
- 登录事件按 Full、IpEnforceable、ObserveOnly 分级；不伪造 Unknown。
- 一期只支持 Windows/Linux，不支持 macOS 和中心管理；MCP 后续已作为可选扩展实现（默认停止，需管理员显式启用并创建受限 API Key，调用进入审计）。
- 防火墙联动属于一期能力，但不提供防火墙自动恢复、规则对账、历史补写或恢复动作审计。

## 二、名单和地域

### IPB-01 名单条目与范围（P0，M2）

支持单 IP 和 CIDR，覆盖 IPv4/IPv6。保存类型、值、作用范围、原因、创建者、生效时间、到期时间、状态和来源。保存前规范化和校验，重叠、冲突和白名单优先级可预览。

### IPB-02 名单匹配和优先级（P0，M2）

白名单和例外优先于黑名单和自动策略。冲突按显式优先级处理，不依赖加载顺序。判定结果包含命中条目、优先级、原因和版本。

### IPB-03 名单到期和状态（P0，M2）

支持观察、生效、已到期、已解除和停用。到期处理幂等，不重复解封。

### IPB-04 名单导入导出和批量操作（P1，M3）

导入保留来源、版本、许可和校验和。批量操作需要二次确认、影响预览和逐条结果。导出受权限、条数和字段范围限制并写审计。

### IPB-05 地域策略（P1，M3）

登记 GeoIP 数据集来源、版本、许可和校验和。内网、回环、保留和未知地址单独处理。命中记录引用使用的数据集版本，不把推断表示为精确位置。

## 三、登录采集和连接关联

### IPB-06 Windows 登录采集（P0，M2）

支持 RDP、OpenSSH、WinRM 的成功和失败事件，采集 Security 4624/4625 及对应 Operational 日志，保存原始事件 ID、采集器和证据来源。

### IPB-07 Linux 登录采集（P0，M2）

支持 SSH 和 VNC。SSH 支持 journald、auth.log、secure。VNC 使用具体实现适配器；实现未提供用户名时允许进入 IpEnforceable。

### IPB-08 连接端点和进程关联（P0，M2）

关联远端 IP/端口、本地 IP/端口和本机服务进程。回环连接额外关联发起进程。Windows 使用 WFP/ETW/4688，Linux 使用 auditd/eBPF/proc。不能取得可靠远端 IP 时不得执行 IP Ban。

### IPB-09 事件完整性分级（P0，M2）

Full 事件可参与全部策略。IpEnforceable 事件只要求可靠远端 IP、协议、时间和登录结果，可参与 IP 级别 Ban。ObserveOnly 只记录和告警。字段缺失使用 NotProvided、NotCollected、CorrelationFailed 或 NotApplicable。

## 四、判定、封禁和会话

### IPB-10 自动封禁策略（P0，M3）

支持阈值、统计窗口、观察期、冷却期、封禁时长和重复触发合并。策略版本化，重复触发不能叠加为永久封禁。事件缺口不当作零。

### IPB-11 人工封禁（P0，M3）

支持 IP/CIDR、原因、到期时间、操作者和二次确认。批量封禁逐条返回结果。

### IPB-12 封禁记录和解封（P0，M3）

记录来源、范围、动作、命中依据、策略版本、状态、到期、解除操作者和原因。支持自动到期、人工解封和误封处理。记录 BanDecision 与 FirewallAction。

### IPB-13 判定引擎和离线回放（P0，M3）

输入来源标识、名单快照、策略版本和观测窗口，输出命中条目、动作、分值和原因。同一输入结果确定。测试不依赖数据库、网络或真实主机。

### IPB-14 当前连接页面（P0，M3）

展示当前 TCP 连接、监听端口、连接状态、远端/本地端点和进程。当前快照与历史登录事件分开。

### IPB-15 当前登录会话页面（P0，M3）

展示 SSH、RDP、VNC、WinRM 活动会话、用户名、远端 IP、登录时间和关联事件。支持查看对应的网络连接。

### IPB-16 已有会话断开（P1，M3）

普通 Ban 默认只阻止新连接。人工立即断开需要二次确认。支持 Linux/Windows 会话终止或删除连接状态。不支持时返回明确结果，不能假报成功。

## 五、防火墙执行

### IPB-17 防火墙 Provider（P0，M4）

Windows 支持 Windows Defender Firewall/WFP。Linux 支持 firewalld、ufw、nftables、iptables。provider 支持 Detect、Capabilities、Ban、Unban、HealthCheck。只选择一个活动 provider，使用 IPBan 专属规则集合，操作幂等。

### IPB-18 防火墙状态和失败（P0，M4）

状态至少包括 Enabled、Disabled、Unsupported、PermissionDenied、CommandFailed。防火墙关闭时继续采集和生成 BanDecision，FirewallAction 标记 Disabled/Failed，页面显示 ProtectionDegraded。不提供一键恢复、自动恢复、规则对账、历史补写、自动重试队列和恢复动作审计。防火墙恢复后旧失败动作不自动下发。

## 六、账号、审计和管理面

### IPB-19 多用户和 HTTPS（P0，M1）

支持多个账号，所有账号同权，不做 RBAC。默认 HTTPS、自签名证书、证书上传和重启生效。默认监听 IPv4 0.0.0.0，IPv6 不默认开启。账号、证书上传、服务重启和批量操作需要认证和二次确认。

### IPB-20 可靠操作审计（P0，M1/M3）

覆盖登录、账号、名单、策略、封禁、解封、会话断开、系统设置、证书和备份。审计不可用时，管理写操作不得报告成功。不记录密码、私钥、Token、连接串或完整敏感原文。

### IPB-21 看板、统计和导出（P1，M5）

展示封禁趋势、命中来源、策略效果、数据缺口、防火墙降级和日志容量。统计与记录查询口径一致。支持 CSV/JSON/NDJSON 导出。

## 七、存储、日志和发布

### IPB-22 SQLite 自动创建和迁移（P0，M1）

启动自动创建 SQLite 并执行正向非破坏性迁移，使用 WAL、迁移锁、事务和迁移历史。迁移前备份。迁移失败时不启动 Agent 和防火墙执行。不自动执行删表、清空和不可逆重建。

### IPB-23 日志留存、轮转和备份（P0，M5）

登录事件保留 365 天，支持自动轮转、压缩、导出、数据库备份和备份校验。页面展示数据库、日志、归档大小、最早事件、最后轮转和最后备份。

### IPB-24 Native AOT 和发布（P1，M6）

使用 Minimal API、源生成 JSON、静态 provider 注册。发布 win-x64、win-arm64、linux-x64、linux-arm64、linux-musl-x64。Windows Service 和 systemd 均需验证。Yitter、SQLite、WFP 和 eBPF helper 需要 AOT 发布测试。

### IPB-25 部署和单机运行（P0，M1/M6）

每台 Windows/Linux 主机独立安装。Api 与 Agent 通过本机 IPC 通信。不支持中心管理、跨主机策略下发和 macOS。前端构建结果复制到 Api 的 wwwroot。

## 八、后续候选

MCP/AI（后续已作为可选扩展实现：默认停止，需管理员显式启用并创建受限 API Key，调用进入审计）、macOS、中心管理、多实例策略、RBAC、第三方商业防火墙、威胁情报、WAF-Lite 联动和反向代理数据面不属于一期。

| M2 | IPB-06 至 IPB-09 | Windows/Linux 事件采集、连接关联和能力分级通过 |
