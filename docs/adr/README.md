## 需要 ADR 的议题

- SQLite 迁移、备份、容量和审计边界；
- Agent/Api 双进程、IPC 和 YiteId WorkerId 分配；
- Full/IpEnforceable/ObserveOnly 事件合同；
- Windows/Linux 连接和进程关联；
- 防火墙 provider、Disabled/Failed 语义和规则所有权；
- 名单、策略和 BanDecision 版本化；
- 观测数据去重和时间窗口；
- Native AOT 兼容性和发布矩阵。

## 状态和模板

状态为提议、接受、拒绝或已被替代。文件名使用 ADR-0001-标题.md，编号递增，不复用。

模板：

    # ADR-0001 标题
    - 状态：提议 / 接受 / 拒绝 / 已被替代
    - 日期：YYYY-MM-DD
    - 相关：方案、接口、版本记录链接

    ## 背景
    ## 决定
    ## 理由
    ## 影响
    ## 后续
