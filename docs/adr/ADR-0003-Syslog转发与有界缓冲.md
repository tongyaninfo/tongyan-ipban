# ADR-0003 Syslog 转发与有界缓冲

- 状态：接受
- 日期：2026-11-11
- 相关：[实施方案](../spec/Syslog转发与日志分级实施方案.md)、[接口合同](../api/README.md)

## 背景

运行日志、业务事件和管理审计分属不同来源。仅转发现有日志文件会漏掉已经持久化的主机登录、封禁执行和管理审计。

## 决定

API 和 Agent 分别接入结构化运行日志和已持久化的业务事件，使用统一中文正文、Syslog 分级、主机与模块名。登录失败、封禁决定和执行事件使用级别 0，优先占用保留空间并优先投递。运行日志与本地业务审计仍各走原有持久化路径。

配置使用现有 `system_settings`，不增加迁移或表结构。全局配置版本用于并发控制；单目标投递版本用于隔离目的地、协议和 TLS 验证规则改变前的积压。

转发使用进程内有界队列与按目标版本隔离的磁盘分段；先完整写盘再发送，接受进程被强制终止时从本地业务提交到写盘之间的丢失窗口。发送与本地数据库事务不组成分布式事务。目标故障不阻塞其他目标或业务线程。若以后要求业务提交和出站事件原子持久化，应另行评估事务 outbox 及迁移。

## 影响

UDP、TCP、TLS 的写入结果不能作为接收端落盘证据；RELP 确认丢失可导致重发，保留稳定事件 ID 供去重。设置变更、过期、截断、磁盘不可用和优先队列耗尽均需可观察。实际容量和延迟以隔离压测为准。
