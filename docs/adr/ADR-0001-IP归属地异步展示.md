# ADR-0001 IP 归属地异步展示

- 状态：接受
- 日期：2026-11-10
- 依据：用户确认新增 IP 数据库配置、默认关闭、后台异步解析及所有来源 IP 换行展示的实施方案。
- 相关：[接口合同](../api/README.md)、[变更日志](../../CHANGELOG.md)

## 背景

管理台需要展示来源 IP 的归属地，并允许选择通研 IP 查询接口的六个数据库。外部查询存在超时、数据缺失和不同数据库结果不一致的情况，不能延长登录事件、连接、名单和封禁业务的响应时间。

## 决定

1. 解析服务运行在管理 API 宿主，接口 `IIPLocation` 的通研实现为 `TongYanIPLocation`。不接入 Agent 采集、防火墙或纯函数判定引擎。
2. 复用 `system_settings` 存储整份配置，保存与可靠审计使用同一事务；不新增数据表、列或迁移。通用设置接口不得绕过专用校验更新此配置。
3. 默认关闭，默认接口为 `https://ip.tongyaninfo.com/`，数据库为 `CZ88`，超时为 2 秒。支持 `CZ88`、`ip2location`、`ip2region`、`dbip`、`ipinfo`、`geolite2` 单选。
4. 页面单独批量申请解析，管理接口只读取缓存和尝试入队，不等待外部接口。后台采用有界队列、固定并发、同 IP 去重和有容量限制的内存缓存；队列满时返回忙状态。
5. 配置切换使旧缓存失效、取消旧任务，并阻止旧结果回填。失败短暂缓存，不持续重试。缓存不写入业务数据，重启后按需重新解析。
6. 来源 IP 先显示，结果到达后补在下一行。内网、回环、保留地址本地识别，CIDR 明确作为网段处理。原始日志与请求响应证据不扫描改写。
7. 只展示接口实际返回的字段，并保留数据库、版本和归属声明。IP 归属地是数据库推断，不作为精确位置或封禁依据。

## 理由与影响

这样可保留现有业务 API、IPC 和存储合同，并把外部服务故障限制在归属地展示范围。管理员开启功能后，页面中的公网来源 IP 会发送至所配置的查询服务；配置页应说明此行为。固定并发与容量限制可约束资源消耗，但不代表已经完成压力测试或具备特定性能指标。

## 验证边界

验证关闭不查询、超时、异常、重复 IP、队列饱和、配置切换、缓存容量和审计失败；浏览器检查各来源展示点及错误、空数据和窄屏状态。实际运行结果维护在根 [变更日志](../../CHANGELOG.md) 中，部署和真实宿主防火墙验证不属于此次授权范围。
