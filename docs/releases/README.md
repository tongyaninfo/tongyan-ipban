# 版本与发布

本目录记录版本规则、发布清单、数据库升级和 Native AOT 制品约定。当前源码为 0.1.0 工程初始化版本，尚未封版；后端、前端和本机 AOT 冒烟制品已可构建，数据库与生产制品尚未验收。

## 版本规则

- 根 VERSION 是产品版本唯一来源，当前为 0.1.0。
- CHANGELOG 面向使用者；开发依据、验证边界和范围调整在内部开发记录中维护，不随公开仓库发布。
- 后端、前端和安装包版本从根版本投影，不各自维护另一套版本。
- 数据库迁移编号独立记录，不能重写历史迁移。

## 数据库启动和升级

- 服务启动自动创建 SQLite，并执行连续的正向、非破坏性迁移。
- 使用单实例迁移锁、事务和迁移历史。
- 迁移前生成备份；未知、更高或不连续的数据库版本停止并报告。
- 需要删除数据、清空表或不可逆重建时，不由普通启动自动执行。
- 迁移失败保留原数据库和备份，不覆盖或删除。

## 发布矩阵

规划发布目标：

- win-x64；
- win-arm64；
- linux-x64；
- linux-arm64；
- linux-musl-x64。

前端构建产物复制到 Api 的 wwwroot。Windows 使用 Windows Service，Linux 使用 systemd。发布前必须验证 Yitter、SQLite、WFP 和 eBPF helper 的 Native AOT 兼容性。

## 发布前检查

- 版本、CHANGELOG 和发布记录一致；
- 文档链接和状态标注检查通过；
- dotnet build、dotnet test、npm lint/test/build 实际运行；
- AOT 制品按 RID 启动；
- SQLite 自动迁移、备份和日志留存实际验证；
- 登录采集、当前连接、当前会话、防火墙 provider 和 HTTPS 实际验证；
- 防火墙关闭时没有自动恢复、规则对账或历史补写；
- 制品无真实凭据、私钥、主机信息或客户数据；
- 部署和防火墙验收只在获准隔离环境执行。

当前没有版本发布记录或可部署制品。
