# 通研 IPBan 项目目录规划

本文件说明当前目录职责和一期实施后的目标结构。后端四个项目、测试骨架和前端模板已建立；数据库、传感器和生产发布制品仍按里程碑实现。

## 当前目标结构

    IPBan/
    ├── backend/
    │   ├── src/
    │   │   ├── IpBan.Shared/       # 公共 DTO、ApiResult、IPC 合同
    │   │   ├── IpBan.Engine/       # 纯函数封禁判定
    │   │   ├── IpBan.Agent/        # 采集、传感器、SQLite、防火墙和会话
    │   │   └── IpBan.Api/          # HTTPS API、认证和 wwwroot
    │   └── tests/
    │       ├── IpBan.Engine.Tests/
    │       ├── IpBan.Agent.Tests/
    │       └── IpBan.Api.Tests/
    ├── frontend/                   # Ant Design Pro 管理台
    ├── docs/
    ├── deploy/
    └── scripts/

## 职责

- IpBan.Shared：统一 ApiResult<T>、DTO、枚举、时间和 IPC 合同。
- IpBan.Engine：不依赖 ASP.NET Core，输入名单快照、策略版本和观测窗口，输出确定性的 BanDecision。
- IpBan.Agent：高权限运行，读取 Windows/Linux 登录日志，关联 WFP/ETW/auditd/eBPF，写入 SQLite，调用防火墙 provider，查询和断开当前会话。
- IpBan.Api：绑定 HTTPS 0.0.0.0，提供认证、配置、查询、导出、备份、证书和前端静态文件；通过本机 IPC 调用 Agent。
- 前端：当前连接、当前会话、登录事件、名单、策略、封禁、防火墙、日志、备份、用户、HTTPS 和审计页面。

## 一期边界

一期只支持 Windows/Linux 单机 Agent。防火墙 provider 支持 Windows Defender Firewall/WFP、firewalld、ufw、nftables、iptables。防火墙关闭时记录 Disabled/Failed 和 ProtectionDegraded，不提供恢复、自动恢复、规则对账、历史补写或恢复审计。

一期不支持 macOS、中心管理、RBAC、反向代理数据面、WAF 规则引擎和第三方商业防火墙通用适配；MCP 后续已作为可选扩展实现（默认停止，需管理员显式启用并创建受限 API Key，调用进入审计）。

SQLite 使用 WAL、迁移锁和事务，服务启动自动创建并执行正向非破坏性迁移。结构以真实迁移历史为准。
